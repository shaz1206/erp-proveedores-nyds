# ERP Módulo Proveedores - NYDS

Desarrollado con Python, Flask, SQLAlchemy, Pandas y Bootstrap para la gestión de proveedores, expedientes digitales, control de documentos y trazabilidad de materias primas de NYDS.

## Instrucciones de Instalación y Ejecución

1. Clona este repositorio o descárgalo en formato ZIP y descomprímelo en tu computadora.
2. Abre tu terminal (CMD, PowerShell o VS Code) dentro de la carpeta del proyecto.
3. Instala las librerías de Python requeridas ejecutando el siguiente comando:
   ```bash
   pip install Flask Flask-SQLAlchemy pandas openpyxl Werkzeug
